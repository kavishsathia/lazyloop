# Support

Hamster is experimental and currently maintained on a best-effort basis.

- Use a **bug report** for reproducible defects.
- Use a **feature request** for language, runtime, process-kernel, integration,
  or developer-experience proposals.
- Use a **documentation issue** when the CLI manual and website are unclear or
  inconsistent.
- Follow [SECURITY.md](SECURITY.md) instead of opening a public issue for
  vulnerabilities.

Include the Hamster commit or version, operating system, Codex distribution and
version, relevant `.hmstr` source, and a sanitized trace fixture when possible.
Never attach secrets, credentials, private repository contents, or unsanitized
Codex transcripts.
